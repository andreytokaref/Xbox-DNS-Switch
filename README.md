# Xbox-DNS-Switch

> 🎮 Скрипт (.bat) для быстрой смены DNS с DHCP на **Xbox-DNS** (и обратно) без ручной настройки.

---

## ⚙️ Настройка имени интерфейса

По умолчанию в скрипте используется адаптер **`Ethernet`**.  
Если у вас **Wi-Fi** или другое имя — скрипт не сработает. Нужно указать правильное имя вручную.

### 🔍 Как узнать имя интерфейса

1. Откройте командную строку (**можно без прав администратора**).
2. Введите команду:

   ```cmd
   netsh interface show interface


3. Найдите столбец «Имя интерфейса» для вашего активного подключения
(состояние — «Подключен»). Например: Беспроводная сеть, Wi-Fi, Ethernet.

![скрин с консоли](images/image1.png)

4. Впишите это имя в переменную INTERFACE_NAME в скрипте.

⚠️ Если имя на русском — пишите именно так, как оно отображается.

![скрин с кода](images/image2.png)

## ✨ Возможности

- 🔒 Настройка **частного DNS** с поддержкой **DNS-over-HTTPS (DoH)**
- 🔄 Быстрое переключение между статическим DNS и DHCP (Авто)
- 🖥️ Простое меню — выбор цифрой
- 🧹 Автоматическая очистка DNS-кэша

---

## 📡 Используемые серверы

| Параметр        | Значение                          |
|-----------------|-----------------------------------|
| **Основной DNS**  | `111.88.96.50`                    |
| **Резервный DNS** | `111.88.96.51`                    |
| **DoH-шаблон**    | `https://xbox-dns.ru/dns-query`   |

---

## ⚠️ Важно

> **Запускайте скрипт только от имени Администратора!**
>
> Иначе `netsh` не сможет изменить сетевые настройки.

Для запуска: правый клик по `.bat` файлу → **«Запуск от имени администратора»**.

---

## 🚀 Как пользоваться

1. Запустите скрипт от имени администратора.
2. В меню выберите нужный пункт:

   | Пункт | Действие |
   |-------|----------|
   | `1` | Включить частный DNS (Static + DoH) |
   | `2` | Переключить на Авто (DHCP) |
   | `3` | Выход |
